# 打开设置卡顿优化与验证

日期：2026-11-16。范围仅公共设置插件及本仓库测试，不修改游戏、宿主、DIYLevel 或 FastInit 原 DLL。

本文保留首次性能优化阶段的基准与回归。后续界面配色和固定按钮列的最终复测见[当前界面修订](settings-feedback.md)：30测试MOD，cold submit11.792ms、内容110.136ms完成，六次重开平均8.363ms，44项通过；不将各阶段断言累计成当前版本覆盖数。

## 原因与修改

真实入口测量表明，原先每次打开都调用 `Reload → BuildSettings`，同步销毁两栏并重新创建控件。
30个测试 MOD 加已安装 MOD 的场景，每次重新打开创建73个按钮、82个文本、25个设置行；
配置扫描约1.1–1.2毫秒，并非主要耗时。首次还包括 JIT、模板实例化和首次编辑器构建。

- `NativePage.Layout.cs`：打开时比较配置项引用、显示元数据、API修订、语言、输入域和会话选择，
  不变时保留两栏及自定义编辑器实例，回读真实配置值，恢复滚动和子控件导航。
- 首次先显示原生框架，再在主线程以约4毫秒预算分批创建 MOD列表和设置行；
  预算按完整行检查，不能中途抢占单个消费方 `Create` 回调。加载可取消，重开会重新完成。
- 内置控件在非活跃内容容器内完成属性设置，再统一启用，减少构建中的 UI 注册。
  自定义工厂仍保留活跃容器语义；关闭只 Cancel/释放输入，结构重建或页面销毁才 Dispose。
- 显式刷新复用已获得的目录快照，避免紧接着再次扫描；无布局变化的重开不强制刷新全部 Canvas。
- 编辑器模板查找包含非活跃子项，保证批量构建仍取到真实文本；单次导航布线只解析一次记忆目标。

## 测量方法与结果

命令：`scripts/test-unity.ps1 -WithoutFastInit -FixtureCount 30 -OpeningPerformance`；
去掉 `-WithoutFastInit` 可验证已安装 FastInit 组合。使用真实 Unity、原生厨师入口的 submit 事件，
Stopwatch 测回调及随后各帧间隔，测试 DLL 通过 Harmony 累计生产调用耗时。
`submitMs` 是主线程入口回调耗时，`readyMs` 是内容完成时间；不是物理按键到屏幕的端到端延迟。
观测帧间隔包含其他 MOD、渲染和系统调度，并非独立 Unity Profiler CPU 时间。

| 场景 | 首次 submit | 六次重复打开 submit | 内容完成 | 首次最大观测帧间隔 |
|---|---:|---:|---:|---:|
| 修改前，无FastInit | 78.604 ms | 54.732–73.465 ms，平均59.191 ms | 未单列 | 首个111.268 ms |
| 最终实现，无FastInit | 11.893 ms | 6.757–7.445 ms，平均7.079 ms | 93.784 ms | 19.486 ms |
| 最终实现，有FastInit | 17.009 ms | 10.268–11.058 ms，平均10.570 ms | 133.798 ms | 25.305 ms |

无FastInit前后保留相同30个测试 MOD、25个当前设置行和现有安装组合；重复打开平均耗时下降约88%。
有FastInit场的可选 MOD 组合不同，单独列出，不与基线直接计算提升。分帧创建减少单帧阻塞，
并不声称总创建时间或所有机器的端到端耗时都缩短。

基线失败证据：`.validation/20261116-181916-783-without-fastinit`，
18项时在“重复打开保留MOD控件”断言失败；文件保留全部七次采样。
最终有FastInit性能场：`.validation/20261116-184412-494-with-fastinit`，44项通过。
最终无FastInit性能场：`.validation/20261116-184745-346-without-fastinit`，44项通过。
覆盖首次帧/完成时间、六次重开、控件引用保持、隐藏期间值与配置结构变更、
显式刷新、自定义编辑器创建/刷新/单次释放、滚动和复合子控件导航，以及首次加载取消后重开。

## 安全边界与未验证项

每场测试启动前拒绝现有游戏进程；最初发现另一个项目的测试进程后保留，待其自行退出才启动。
全部测试使用原有存档隔离/临时安装入口，退出后核对原存档并恢复安装。
最终三场证据再次执行26项安装文件/原存档的存在性与SHA256核对，全部通过，无残留游戏进程。
游戏日志仍有其他MOD和游戏的告警，未声称零告警。

物理键鼠/手柄、IME、真实联机、其他分辨率、极大量配置、自定义工厂重型同步工作没有性能保证；
本次没有重跑所有跨版本共享服务矩阵。构建没有正式部署；安装新DLL后须重启游戏，
若其他宿主内置同GUID实现，需要同步更新公共源码，避免同版本不同实现被加载器选中。
