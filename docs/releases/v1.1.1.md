# MOD Settings / MOD 设置 v1.1.1

## 中文

- 设置页面的按钮、搜索、改键、色板及校验提示支持游戏全部12种语言，并跟随游戏语言刷新。
- 修复MOD独立切换语言后下拉菜单未更新的问题：当前值、候选项及已打开的列表同步刷新，保留焦点、滚动位置和原始配置值。
- 随源码提供SDK及`ModSettingsAttributes`，其他MOD无需依赖Configuration Manager即可声明显示元数据、注册业务按钮并刷新设置；公共API保持v1。

## English

- Buttons, search, key rebinding, the color picker, and validation messages now follow all 12 game languages.
- Dropdowns now refresh when a MOD changes its own language, including the current value, options, and an already open list, while preserving focus, scroll position, and stored values.
- Includes the source SDK and `ModSettingsAttributes` for display metadata, action buttons, and refresh requests without a Configuration Manager dependency. The public API remains v1.

## 한국어

- 버튼, 검색, 키 변경, 색상 선택기 및 입력 검증 안내가 게임의 12개 언어를 지원하며 게임 언어 변경을 따릅니다.
- MOD 자체 언어를 변경하면 드롭다운의 현재 값, 선택 항목 및 열린 목록도 갱신됩니다. 포커스, 스크롤 위치 및 저장된 값은 유지됩니다.
- Configuration Manager 의존성 없이 표시 메타데이터, 동작 버튼 및 새로 고침을 제공하는 소스 SDK와 `ModSettingsAttributes`를 포함합니다. 공개 API는 v1을 유지합니다.

## 日本語

- ボタン、検索、キー変更、カラーピッカー、入力エラー表示がゲームの全12言語に対応し、ゲームの言語変更に追従します。
- MOD独自の言語を変更した際、ドロップダウンの現在値、選択肢、開いている一覧も更新します。フォーカス、スクロール位置、保存値は維持します。
- Configuration Managerに依存せず、表示メタデータ、アクションボタン、設定の更新を扱えるソースSDKと`ModSettingsAttributes`を同梱します。公開APIはv1のままです。

## 安装与兼容

1. 适用于Windows Steam版《胡闹厨房2》，需要已安装BepInEx 5 / HarmonyX。
2. 下载`OC2ModSettings-v1.1.1.zip`，解压后将`OC2ModSettings.dll`替换到游戏的`BepInEx/plugins`，重启游戏生效。ZIP平铺且仅含此DLL，四个图标资源已嵌入。
3. 不需要Configuration Manager、DIYLevel或FastInit；历史cfg的section/key和值保持不变。固定GUID为`com.ch3ngyz.plugin.overcooked2.modsettings`。
4. SDK及Attributes位于源码的`sdk/`。MOD独立语言应通过`ObjToStr`提供动态译文，批量更新元数据后调用`client.Refresh()`；启动时固定生成的字符串不会自动翻译。
5. 源码内置提供端需同步完整源码、资源及版本。同版本副本必须是相同实现；BepInEx选择最高版本的公共服务，更新后需重启。
