# MOD Settings / MOD 设置 v1.3.1

## 中文

- 右栏的分区标题、配置项名称和独立动作标题改用与「刷新」按钮相同的字体。面板主标题的字体不变。
- 适用于 Windows Steam 版《胡闹厨房 2》，需要 BepInEx 5 / HarmonyX。退出游戏，解压仅含 `OC2ModSettings.dll` 的 `OC2ModSettings-v1.3.1.zip`，替换 `BepInEx/plugins` 中的旧 DLL，再重启游戏。

## English

- Category headings, setting names, and standalone action titles in the right pane now use the same typeface as the **Refresh** button. The main banner keeps its original typeface.
- For Overcooked! 2 on Windows Steam with BepInEx 5 / HarmonyX. Close the game, extract the single `OC2ModSettings.dll` from `OC2ModSettings-v1.3.1.zip`, replace the old DLL in `BepInEx/plugins`, and restart the game.

## 한국어

- 오른쪽 패널의 분류 제목, 설정 이름, 독립 실행 항목 제목에 **새로 고침** 버튼과 같은 글꼴을 사용합니다. 패널의 메인 제목은 기존 글꼴을 유지합니다.
- Windows Steam판 Overcooked! 2와 BepInEx 5 / HarmonyX가 필요합니다. 게임을 종료한 뒤 `OC2ModSettings-v1.3.1.zip`에 들어 있는 `OC2ModSettings.dll` 하나를 꺼내 `BepInEx/plugins`의 기존 DLL을 교체하고 게임을 다시 시작하세요.

## 日本語

- 右ペインのカテゴリ見出し、設定項目名、独立したアクションのタイトルに、**更新**ボタンと同じ書体を使用します。パネルのメインタイトルの書体は従来どおりです。
- Windows Steam 版 Overcooked! 2 が対象で、BepInEx 5 / HarmonyX が必要です。ゲームを終了し、`OC2ModSettings-v1.3.1.zip` に入っている唯一のファイル `OC2ModSettings.dll` で `BepInEx/plugins` の旧 DLL を置き換えてから、ゲームを再起動してください。
