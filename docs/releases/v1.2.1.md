# MOD Settings / MOD 设置 v1.2.1

## 中文

- 修复鼠标移出输入框就不能继续打字的问题。搜索、数值和色板输入会保留光标和选区；点击其他控件仍可切换或结束编辑。
- 搜索框旁新增「×」按钮，一键清空筛选并回到搜索框，继续输入。
- 精简面板标题，在标题条显示当前插件版本。双栏列表上移，左下角快捷键按钮与 MOD 列表左侧对齐。

## English

- Text fields keep their caret and selection when the pointer moves away, so you can keep typing in search, numeric fields, and the color picker. Clicking another control still switches or ends editing.
- Use the new × button next to search to clear the filter and return focus to the search field.
- The panel has a simpler title and shows the current plugin version in the header. Both lists start higher, and the shortcut button aligns with the left edge of the MOD list.

## 한국어

- 마우스 포인터가 입력란을 벗어나도 커서와 선택 영역이 유지되어 검색, 숫자 입력, 색상 선택 창에서 계속 입력할 수 있습니다. 다른 컨트롤을 클릭하면 편집이 전환되거나 종료됩니다.
- 검색창 옆에 × 버튼을 추가했습니다. 누르면 필터가 지워지고 검색창으로 포커스가 돌아옵니다.
- 패널 제목을 간결하게 바꾸고 제목 표시줄에 현재 플러그인 버전을 표시합니다. 양쪽 목록을 위로 올리고 왼쪽 아래 단축키 버튼을 MOD 목록의 왼쪽에 맞췄습니다.

## 日本語

- マウスポインターが入力欄から離れても、カーソルと選択範囲が維持され、検索欄・数値欄・カラーピッカーで入力を続けられます。他の操作項目をクリックすると、編集を切り替えるか終了します。
- 検索欄の横に × ボタンを追加しました。押すと絞り込みが解除され、検索欄にフォーカスが戻ります。
- パネルのタイトルを簡潔にし、ヘッダーに現在のプラグインバージョンを表示します。左右のリストを上に寄せ、左下のショートカットボタンを MOD リストの左端に揃えました。

## 安装与兼容

适用于 Windows Steam 版《胡闹厨房 2》，需要 BepInEx 5 / HarmonyX。退出游戏，解压 `OC2ModSettings-v1.2.1.zip`，把 `OC2ModSettings.dll` 放进 `BepInEx/plugins` 替换旧版，再启动游戏。首次成功读取存档且主菜单可操作后，可用设置中的快捷键打开面板。

插件 GUID `com.ch3ngyz.plugin.overcooked2.modsettings`、公共 API v1 和原有配置保持兼容。使用源码内置的 MOD 应同步公共提供端实现及资源。
