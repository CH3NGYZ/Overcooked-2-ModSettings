# MOD Settings / MOD 设置 v1.3.0

## 中文

- **MOD 文案跟随游戏语言。** 新接入的 MOD 用 SDK 一次提交全部 12 种语言，面板自动选择。`BepInEx/translate/<语言>/<MOD GUID>.txt` 中的 UTF-8 文件也能补充译文。每个字段按「当前语言 API → 当前语言文件 → 英文 API → 英文文件 → 原文」查找。改动翻译文件后需重启游戏。
- **配置名和按钮文字可以分别设置。** MOD 名称、分区、配置项名称和说明都可翻译，不改变配置文件里的键和值。独立动作的行标题与按钮文字可不同，配置项旁的动作按钮也能单独设置文字。旧格式只提供动作标题时，按钮仍默认使用该标题。
- **改键时能看见重复绑定。** 设置面板可识别已列出的单键、组合键和面板开关键；重复绑定会显示黄色标记，查看底部提示即可知道哪些 MOD 和设置用了相同按键。`F8` 与 `Ctrl+F8` 不算重复，提示也不会阻止保存。
- **改名不打乱 MOD 列表。** MOD 的显示名称可以单独更新，置顶和组内排序仍按插件 GUID，不随译名改变。本插件 GUID 仍为 `com.ch3ngyz.plugin.overcooked2.modsettings`；继续使用公共 API v1。
- **安装与升级。** 适用于 Windows Steam 版《胡闹厨房 2》，需要 BepInEx 5 / HarmonyX，不需要 Configuration Manager、DIYLevel 或 FastInit。退出游戏，解压 `OC2ModSettings-v1.3.0.zip`，将 `OC2ModSettings.dll` 放入 `BepInEx/plugins` 替换旧版后重新启动；在「厨师 → MOD 设置」标题栏确认实际加载的是 1.3.0。若由其他 MOD 内置提供公共服务，新功能需要实际加载 1.3.0 或更新的实现。

## English

- **MOD text follows the game's language.** New integrations submit all 12 languages in one SDK call, and the panel chooses what to display. UTF-8 files at `BepInEx/translate/<language>/<MOD GUID>.txt` can supply additional translations. Each field looks up text in this order: current-language API → current-language file → English API → English file → original text. Restart the game after changing a translation file.
- **Name settings and buttons separately.** Translate MOD names, category headings, setting names and descriptions without changing the keys or values in the config file. A standalone action can have a different row title and button label, and buttons beside settings can have their own labels. If an older action provides only a title, its button still uses that title by default.
- **Spot duplicate shortcuts when rebinding.** A yellow marker flags identical bindings among listed single keys, key combinations, and the panel toggle. The hint at the bottom identifies the conflicting MODs and settings. `F8` and `Ctrl+F8` are different bindings, and warnings don't block saving.
- **Renaming a MOD doesn't reorder the list.** MOD names can be updated independently; pins and sorting within each group still use plugin GUIDs. This plugin keeps the GUID `com.ch3ngyz.plugin.overcooked2.modsettings` and continues to use public API v1.
- **Installation and updates.** For Overcooked! 2 on Windows Steam. Requires BepInEx 5 / HarmonyX; Configuration Manager, DIYLevel, and FastInit are not required. Close the game, extract `OC2ModSettings-v1.3.0.zip`, replace the old `OC2ModSettings.dll` in `BepInEx/plugins`, then restart. Check the header in **Chefs → MOD Settings** for version 1.3.0. If another MOD embeds the shared service, the new features require the loaded implementation to be 1.3.0 or later.

## 한국어

- **MOD 설정의 문구가 게임 언어를 따릅니다.** 새로 연동하는 MOD는 SDK를 한 번 호출해 12개 언어의 번역을 모두 등록하며, 설정 화면이 표시할 언어를 선택합니다. `BepInEx/translate/<언어>/<MOD GUID>.txt`의 UTF-8 파일로 번역을 보완할 수 있습니다. 각 항목은 현재 언어의 API → 현재 언어의 파일 → 영어 API → 영어 파일 → 원문 순으로 번역을 찾습니다. 번역 파일을 변경한 뒤에는 게임을 다시 시작해야 합니다.
- **설정 이름과 버튼 문구를 따로 지정할 수 있습니다.** 설정 파일의 키나 값을 변경하지 않고 MOD 이름, 분류 제목, 설정 이름과 설명을 번역할 수 있습니다. 독립 실행 항목의 제목과 버튼 문구를 다르게 지정하거나 설정 옆 버튼에 별도 문구를 붙일 수 있습니다. 기존 형식으로 제목만 지정하면 버튼에는 기본적으로 그 제목이 표시됩니다.
- **단축키를 바꿀 때 중복을 확인할 수 있습니다.** 설정에 표시되는 단일 키, 조합 키, 패널 열기·닫기 키 간에 동일한 지정이 있으면 노란색 표시가 나타납니다. 하단 안내에서 어떤 MOD와 설정이 같은 키를 쓰는지 확인할 수 있습니다. `F8`과 `Ctrl+F8`은 서로 다른 단축키이며, 경고가 떠도 저장할 수 있습니다.
- **MOD 이름을 바꿔도 목록 순서는 그대로입니다.** 표시 이름은 따로 바꿀 수 있고, 고정 상태와 그룹 내 정렬은 계속 플러그인 GUID를 기준으로 합니다. 이 플러그인의 GUID는 `com.ch3ngyz.plugin.overcooked2.modsettings`로 유지되며 공개 API v1을 계속 사용합니다.
- **설치 및 업데이트.** Windows Steam판 Overcooked! 2에서 사용합니다. BepInEx 5 / HarmonyX가 필요하며 Configuration Manager, DIYLevel, FastInit은 필요하지 않습니다. 게임을 종료한 뒤 `OC2ModSettings-v1.3.0.zip`의 압축을 풀고, `BepInEx/plugins`의 기존 DLL을 `OC2ModSettings.dll`로 교체한 다음 게임을 다시 시작하세요. **셰프 → MOD 설정** 화면 상단에서 1.3.0이 로드되었는지 확인할 수 있습니다. 다른 MOD에 내장된 공용 서비스를 사용한다면 실제로 로드된 버전이 1.3.0 이상이어야 새 기능을 쓸 수 있습니다.

## 日本語

- **MOD の表示テキストがゲームの言語に連動します。** 新たに連携する MOD は SDK の 1 回の呼び出しで全 12 言語を登録し、設定画面が表示言語を選びます。`BepInEx/translate/<言語>/<MOD GUID>.txt` の UTF-8 ファイルでも翻訳を補えます。各項目は現在の言語の API → 現在の言語のファイル → 英語の API → 英語のファイル → 原文の順に参照します。翻訳ファイルを変更した後はゲームを再起動してください。
- **設定名とボタンの文言を別々に指定できます。** 設定ファイルのキーや値を変えずに、MOD 名、カテゴリ見出し、設定項目名と説明を翻訳できます。独立したアクションでは行の見出しとボタンを別の文言にでき、設定項目の横にあるボタンにも個別の文言を付けられます。従来の形式でタイトルのみを指定した場合、既定ではボタンにもそのタイトルを表示します。
- **キーの割り当て変更時に重複を確認できます。** 設定に表示される単独キー、キーの組み合わせ、パネルの開閉キーに同じ割り当てがあると黄色いマークが表示されます。画面下部の案内で、同じキーを使う MOD と設定を確認できます。`F8` と `Ctrl+F8` は別の割り当てで、警告が表示されても保存できます。
- **MOD 名を変えても一覧の順番は変わりません。** 表示名は個別に変更できますが、ピン留めとグループ内の並び順は引き続きプラグインの GUID に基づきます。このプラグインの GUID は `com.ch3ngyz.plugin.overcooked2.modsettings` のままで、公開 API v1 を引き続き使用します。
- **インストールと更新。** Windows Steam 版 Overcooked! 2 が対象です。BepInEx 5 / HarmonyX が必要で、Configuration Manager、DIYLevel、FastInit は不要です。ゲームを終了し、`OC2ModSettings-v1.3.0.zip` を展開します。`BepInEx/plugins` にある旧版を `OC2ModSettings.dll` で置き換えてから、ゲームを起動してください。**シェフ → MOD 設定** のヘッダーで 1.3.0 が読み込まれていることを確認できます。別の MOD に組み込まれた共通サービスを使う場合は、実際に読み込まれる実装が 1.3.0 以降であれば新機能を使えます。
