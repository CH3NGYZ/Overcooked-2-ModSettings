# MOD Settings / MOD 设置 v1.2.0

## 中文

- 按钮、输入框和下拉菜单会从当前游戏主题读取普通色和高亮色。更换原生按钮贴图的主题也能跟随取色；滑条高亮时抓手保持白色。
- 左下角只显示当前开关快捷键。点一下即可录入，按 Esc 取消。支持字母、数字、标点、小键盘和 F 键，不限于 F1–F12；Ctrl、Win、Alt、Shift、锁定键、Tab、空格、Esc 和其他保留键不能绑定。
- 在 MOD 设置的输入框中，绑定的普通字符键仍可照常打字。快捷键设置立即保存，默认仍为反引号／波浪号键。

## English

- Buttons, text fields, and dropdowns use the game theme’s normal and highlight colors, including themes that replace the native button textures. The slider handle stays white when highlighted.
- The lower-left button shows only the current toggle key. Click it and press a key to rebind; press Esc to cancel. Letters, digits, punctuation, numpad keys, and F keys are supported. Ctrl, Win, Alt, Shift, lock keys, Tab, Space, Esc, and other reserved keys cannot be assigned.
- A bound character key still types normally in MOD Settings text fields. Changes are saved immediately, and the backquote/tilde key remains the default.

## 한국어

- 버튼, 입력란, 드롭다운에 현재 게임 테마의 일반 색상과 강조 색상을 적용합니다. 기본 버튼 텍스처를 교체한 테마도 지원하며, 슬라이더가 강조되어도 손잡이는 흰색을 유지합니다.
- 왼쪽 아래에는 현재 열기/닫기 키만 표시됩니다. 클릭한 뒤 키를 눌러 변경하고, Esc로 취소할 수 있습니다. 문자, 숫자, 문장 부호, 숫자 키패드, F 키를 지원합니다. Ctrl, Win, Alt, Shift, 잠금 키, Tab, Space, Esc 및 기타 예약 키는 지정할 수 없습니다.
- 문자 키를 지정해도 MOD 설정 입력란에서는 해당 문자를 입력할 수 있습니다. 설정은 즉시 저장되며, 기본값은 백쿼트/물결표 키입니다.

## 日本語

- ボタン、入力欄、ドロップダウンに現在のゲームテーマの通常色と強調色を適用します。標準ボタンのテクスチャを差し替えたテーマにも対応し、強調中もスライダーのつまみは白のままです。
- 左下には現在の開閉キーだけを表示します。クリックしてからキーを押すと変更でき、Esc でキャンセルできます。英字、数字、記号、テンキー、F キーに対応します。Ctrl、Win、Alt、Shift、ロックキー、Tab、Space、Esc などの予約キーは割り当てられません。
- 文字キーを割り当てても、MOD 設定の入力欄ではその文字を入力できます。変更はすぐに保存され、初期設定はバッククォート／チルダキーです。

## 安装与兼容

1. 适用于 Windows Steam 版《胡闹厨房 2》，需要 BepInEx 5 / HarmonyX。退出游戏，解压 `OC2ModSettings-v1.2.0.zip`，把 `OC2ModSettings.dll` 放进 `BepInEx/plugins` 替换旧版，然后重启。
2. 第一次成功读取存档且主菜单可操作后，设置页就可以用快捷键打开。主题颜色在这时读取；换主题后需要重启。
3. 插件 GUID `com.ch3ngyz.plugin.overcooked2.modsettings` 和公共 API v1 保持不变。保留原有配置，包括合法的 `Navigation.ToggleKey`。源码内置提供端应同步完整实现及资源。
