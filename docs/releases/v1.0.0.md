# MOD Settings / MOD 设置 v1.0.0

## 中文

- 首次公开发布《胡闹厨房 2》原生公共 MOD 设置页面，自动发现已加载 MOD 的配置。
- 首次存档读取成功且主菜单可交互后缓存原生素材，使用反引号／波浪号键随时开关；重复打开复用页面并保留位置。
- 提供即时搜索、有效输入立即保存、非法数值提示、鼠标光标定位与拖选、改键和颜色色板。
- 支持 MOD 置顶、独立分区排序、自定义编辑器及独立／配置行旁业务按钮；HostUtilities 存在时固定第一行。
- 统一蓝色控件、橙色焦点和白色选项标题，修复滚动文字裁剪，并支持顶部关闭和面板外点击关闭。

## English

- First public release of a native Overcooked! 2 MOD settings page with automatic discovery of loaded plugins' configuration.
- Caches native UI assets after the first successful save load and interactive main menu. Toggle with the backquote/tilde key; reopening reuses the page and restores its position.
- Includes live search, immediate saving of valid input, validation feedback, mouse caret positioning and text selection, key rebinding, and a color picker.
- Supports pinned MODs, category ordering, custom editors, and standalone or inline action buttons. HostUtilities stays first when present.
- Uses blue controls, orange focus, and white option titles; fixes scrolling text clipping and adds top and outside-panel closing.

## 安装与兼容

1. 适用于 Windows Steam 版《胡闹厨房 2》的 Unity Mono 环境，需要已安装 BepInEx 5 / HarmonyX。
2. 下载 `OC2ModSettings-v1.0.0.zip`，解压后将 `OC2ModSettings.dll` 放入游戏的 `BepInEx/plugins`，重启游戏生效。
3. 不需要 Configuration Manager、DIYLevel 或 FastInit。源码内置方式见仓库 README 与 API 文档；公共服务的同版本副本必须保持完整实现一致。

固定插件 GUID：`com.ch3ngyz.plugin.overcooked2.modsettings`。配置继续保存到各 MOD 自己的 cfg，不重命名历史 section/key；不重置现有配置。

ZIP 平铺且只包含运行 DLL；图钉和开关的四个 PNG 已嵌入程序集。源码请使用 GitHub 提供的 Source code 下载。
